# Thailand Street Traffic — Up/Down People Count Forecasting

## What this project does
Predicts how many people will move up or down per hour at a Thailand
street location using machine learning. The model forecasts the next
3 days hour by hour using recursive forecasting.

## Project structure
- `notebooks/` — main Jupyter notebook with full analysis
- `data/` — sample dataset and dataset description
- `src/` — Python scripts for each pipeline stage
- `models/` — saved model files (generated by running the notebook)
- `reports/figures/` — all generated plots
- `results/` — evaluation metrics and forecast output

## How to run

1. Clone the repo:
   git clone https://github.com/[yourusername]/Thailand-Up-Down-Forecast.git
   cd Thailand-Up-Down-Forecast

2. Install dependencies:
   pip install -r requirements.txt

3. Open the notebook:
   jupyter notebook notebooks/Thailand_Up_Down_Count_Forecast.ipynb

4. Run all cells top to bottom.
